Access 97〜2019 に対応

.mdb / .accdb を、
Access 無しで丸ごと読める

jetdb は Microsoft Access のデータベース（.mdb / .accdb）を読む CLI ツールです。テーブルのデータだけでなく、クエリ・VBA・マクロ・フォームまで取り出せます。macOS・Linux・Windows で動きます。

インストール GitHub 
# テーブルの一覧
$ jetdb tables sales.accdb
# VBA のソースを取り出す
$ jetdb vba show sales.accdb Module1
# PostgreSQL 向けの DDL を作る
$ jetdb schema sales.accdb --ddl postgres

Access も ODBC ドライバも要りません

Rust だけで書かれていて、C のライブラリにも依存しません。手元に .mdb / .accdb しか無くても、そのまま開けます。

macOS・Linux・Windows

Windows や Access のライセンスが無い環境でも動きます。

Access 97〜2019

Jet3（Access 97）から ACE17（Access 2019）まで、.mdb と .accdb の両方を読めます。

パスワード付きのファイル

パスワード付きの .accdb（Agile、RC4 CryptoAPI、Standard AES）も、--password を付けるだけで開けます。

データだけでなく、アプリごと読める

テーブルを抜き出すだけでなく、Access アプリを作り直すときに要るものまで取り出せます。

  • 01テーブルのデータ

    CSV で書き出します。

    jetdb export sales.accdb Customers

  • 02スキーマ

    列・索引・リレーションシップを表示します。

    jetdb schema sales.accdb

  • 03DDL

    SQLite・PostgreSQL・MySQL・Access SQL 向けに作ります。

    jetdb schema sales.accdb --ddl sqlite

  • 04クエリの SQL

    保存済みクエリの SQL を復元します。

    jetdb queries show sales.accdb MonthlySales

  • 05VBA

    標準モジュール・クラスモジュール・フォームのモジュールのソースを取り出します。

    jetdb vba show sales.accdb Module1

  • 06マクロ

    名前付きマクロを SaveAsText 形式のテキストで表示します。

    jetdb macro show sales.accdb AutoExec

  • 07フォーム/レポート

    フォームやレポートと、そのコントロールのプロパティを表示します。

    jetdb form list sales.accdb

  • 08プロパティ

    テーブルやクエリなどのオブジェクトのプロパティを表示します。

    jetdb prop sales.accdb Customers

AI エージェントにそのまま渡せる

特別な連携が無くても、AI エージェントが CLI を呼ぶだけで Access のファイルを読めます。VBA やクエリまで読めるので、Access アプリを丸ごと AI に渡せます。

素直なテキスト出力

CSV、SQL、VBA のソースなど、そのまま読めて加工しやすい形で出します。

いつも同じ順に並ぶ

一覧は名前の順に並びます。同じファイルからは同じ結果が出ます。

空ならエラーにしない

テーブルやクエリが無いときは、空の出力で正常に終わります。エラーは jetdb: で始まる 1 行で標準エラーに出します。

Claude Code では、Skill としても入れられます。

/plugin marketplace add dominion525/agent-skills
/plugin install jetdb-cli@dominion525-skills

ブラウザでも動きます

WebAssembly 版（npm パッケージ jetdb-wasm）を使うと、ブラウザや Node.js から、テーブルのデータ・クエリの SQL・DDL を読めます。ファイルはブラウザの外に出ません。

デモを開くダミー

元のファイルは書き換えません

jetdb はファイルを読み取り専用で開きます。人から渡されたファイルや、一つしか無い古いファイルも、壊す心配をせずに調べられます。
