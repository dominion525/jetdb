Access 97〜Microsoft 365 に対応

.mdb / .accdb を、
Access 無しで丸ごと読める

jetdb は Microsoft Access のデータベース（.mdb / .accdb）を読む CLI ツールです。テーブルのデータだけでなく、クエリ・VBA・マクロ・フォームまで取り出せます。macOS・Linux・Windows で動きます。

インストール GitHub 
# テーブルの一覧
$ jetdb tables jetdb-sample.accdb
# VBA のソースを取り出す
$ jetdb vba show jetdb-sample.accdb modBilling
# PostgreSQL 向けの DDL を作る
$ jetdb schema jetdb-sample.accdb --ddl postgres

Access も ODBC ドライバも要りません

Rust だけで書かれていて、C のライブラリにも依存しません。手元に .mdb / .accdb しか無くても、そのまま開けます。CLI のほか、Rust のライブラリとしても使えます。

macOS・Linux・Windows

Windows や Access のライセンスが無い環境でも動きます。

Access 97〜Microsoft 365

Jet3（Access 97）から ACE17（Access 2019）まで、.mdb と .accdb の両方を読めます。Microsoft 365 の Access で作ったファイルも読めます。

パスワード付きのファイル

パスワード付きの .accdb（Agile、RC4 CryptoAPI、Standard AES）も、--password を付けるだけで開けます。

元のファイルは書き換えません

読み取り専用で開き、ロックファイル（.laccdb）も作りません。人から渡されたファイルも、壊す心配をせずに調べられます。

データだけでなく、アプリごと読める

テーブルを抜き出すだけでなく、Access アプリを作り直すときに要るものまで取り出せます。

※ただし、Access 97 のフォーム/レポートと VBA は取得できません。印刷の設定はバイト列のまま出し、中身は読み解きません。

  • 03DDL

    SQLite・PostgreSQL・MySQL・Access SQL 向けに作ります。

    jetdb schema jetdb-sample.accdb -T tblOrders --ddl postgres
    出力を見る 
    CREATE TABLE "tblOrders" (
    "OrderID" INTEGER NOT NULL GENERATED ALWAYS AS IDENTITY,
    "CustomerID" INTEGER NOT NULL,
    "ProductID" INTEGER NOT NULL,
    "Quantity" SMALLINT NOT NULL,
    "OrderDate" TIMESTAMP WITHOUT TIME ZONE NOT NULL,
    "Shipped" BOOLEAN,
    PRIMARY KEY ("OrderID")
);

ALTER TABLE "tblOrders" ADD CONSTRAINT "fkOrdersCustomers"
    FOREIGN KEY ("CustomerID") REFERENCES "tblCustomers" ("CustomerID");
ALTER TABLE "tblOrders" ADD CONSTRAINT "fkOrdersProducts"
    FOREIGN KEY ("ProductID") REFERENCES "tblProducts" ("ProductID");

  • 04クエリの SQL

    保存済みクエリの SQL を復元します。

    jetdb queries show jetdb-sample.accdb qryMonthlySales
    出力を見る 
    SELECT Format(tblOrders.OrderDate, 'yyyy-mm') AS SalesMonth, tblCustomers.CustomerName, Sum(tblOrders.Quantity * tblProducts.UnitPrice) AS Total
FROM (tblOrders INNER JOIN tblCustomers ON tblOrders.CustomerID = tblCustomers.CustomerID) INNER JOIN tblProducts ON tblOrders.ProductID = tblProducts.ProductID
GROUP BY Format(tblOrders.OrderDate, 'yyyy-mm'), tblCustomers.CustomerName
ORDER BY Format(tblOrders.OrderDate, 'yyyy-mm'), tblCustomers.CustomerName;

○ 対応　△ 一部対応・条件付き　× 非対応

○ は Access 2000 以降で使えるもの。Access 97 だけの例外は注記に書きます。

  • MDB Tools のクエリの SQL は、SELECT だけを組み立て直します（JOIN・GROUP BY は出ません）。
  • Jackcess のパスワード付きの .accdb は、別のライブラリ Jackcess Encrypt を足すと開けます。この表の項目では、Jackcess の元の版とフォークの結果は同じです。
  • MDB Tools のライセンスは、ライブラリが LGPL-2.0 以降、CLI が GPL-2.0 以降です。
  • mdb-reader のパスワード付きの .accdb は、Standard AES の暗号化に対応していません。
  • jetdb のフォーム/レポートの定義と VBA は、Access 97 のものは読めません。
  • MDB Tools の書き込みは、ライブラリの API で行を追加・更新できるだけです。
  • Jackcess の書き込みは Access 2000 以降で、Access 97 は読み取りだけです。

AI エージェントにそのまま渡せる

jetdb の CLI を入れたうえで jetdb の Skill を入れると、AI エージェントが jetdb を使って Access のファイルを読めるようになります。「この .accdb を PostgreSQL に移したい」と頼めば、テーブルの定義からクエリ・VBA・フォームまで読んで、移行の作業を進められます。

Claude Code

Plugin Marketplace から入れます。

/plugin marketplace add dominion525/agent-skills
/plugin install jetdb-cli@dominion525-skills

ほかのエージェント

skills CLI で入れます。Codex・Cursor・OpenCode などに対応していて、入れ先は実行したときに選べます。 

npx skills add dominion525/agent-skills --skill jetdb-cli

Skill が無くても、CLI の作りが AI に向いています

  • 素直なテキスト出力: CSV、SQL、VBA のソースなど、そのまま読めて加工しやすい形で出します。
  • いつも同じ順に並ぶ: 一覧は名前の順に並びます。同じファイルからは同じ結果が出ます。
  • 空ならエラーにしない: テーブルやクエリが無いときは、空の出力で正常に終わります。エラーは jetdb: で始まる 1 行で標準エラーに出します。

ブラウザでも動きます

WebAssembly 版（npm パッケージ jetdb-wasm）を使うと、ブラウザや Node.js からも、CLI と同じものを読めます。テーブル・クエリ・VBA・マクロ・フォーム・プロパティ・DDL まで扱え、パスワード付きのファイルも開けます。ファイルはブラウザの外に出ません。使い方はJavaScript の API の説明にあります。
