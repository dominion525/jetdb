○ 対応　△ 一部対応・条件付き　× 非対応　? 判断できる根拠が見つからない

○ は Access 2000 以降で使えるもの。Access 97 だけの例外は注記に書きます。

  • 対応バージョンは、その版をコードで扱っているかで判定しました。
  • 複合列は、添付ファイル・複数値・版の履歴の列です。
  • Access 2013 は Access 2010 と同じ形式（ACE14）で保存するため、行を分けていません。
  • アーカイブされたツールと、リリースのないツールは載せていません。

jetdb

  • 複合列は、添付ファイル・複数値・版の履歴の中身を返します。
  • Access 97 のフォーム/レポートは読めません。

MDB Tools

  • ライセンスは、ライブラリが LGPL-2.0 以降、CLI が GPL-2.0 以降です。
  • MSISAM を扱う処理も、拒否する処理もなく、開けるかどうかを判断できませんでした。
  • クエリの SQL は SELECT だけを組み立て直します（JOIN・GROUP BY は出ません）。
  • リレーションシップは、DDL の外部キーとしてだけ出せます（Oracle・PostgreSQL・MySQL）。
  • 書き込みは、ライブラリの API で行を追加・更新できるだけです。
  • 複合列は参照 ID だけです。

Jackcess

  • パスワード付きのファイルと MSISAM は、別のライブラリ Jackcess Encrypt を足すと開けます。
  • プロパティは、データベース・テーブル・列のものを読めます。元の版はクエリのプロパティも読めます。
  • 書き込みは Jet4 と ACE だけです（Access 97 は読み取りだけ）。複合列の新規作成は、元の版の 5.0.3 からできます。

mdb-reader

  • MSISAM は、暗号化されたものを読めません。
  • RC4 CryptoAPI は、非標準の形式を読めません。
  • 複合列は、添付ファイルの中身だけを返します。

access-parser

  • テーブルの列定義を返す公開 API がありません。
  • プロパティは列ごとのものだけです。複合列は参照 ID だけです。

MMKiwi.MdbReader

  • Numeric・複合列・BigInt・DateTimeExtended の列を含むテーブルは、行を読めません。
