○ Supported　△ Partial or conditional　× Not supported　? No evidence found either way

○ means usable with Access 2000 and later. Exceptions that apply only to Access 97 are in the notes.

  • Supported versions are judged by whether the code handles that version.
  • Complex columns are attachment, multivalued, and version history columns.
  • Access 2013 saves files in the same format as Access 2010 (ACE14), so it has no separate row.
  • Archived tools and tools with no release are not listed.

jetdb

  • For complex columns, returns the contents of attachments, multivalued columns, and version history columns.
  • Cannot read Access 97 forms/reports or VBA.

MDB Tools

  • The library is LGPL-2.0 or later, and the CLI is GPL-2.0 or later.
  • There is no code that either handles or rejects MSISAM, so we could not tell whether it opens such files.
  • Reconstructs only SELECT queries (no JOIN or GROUP BY).
  • Relationships are available only as foreign keys in DDL (Oracle, PostgreSQL, MySQL).
  • Writing is limited to adding and updating rows through the library API.
  • Complex columns give only reference IDs.

Jackcess

  • Password-protected files and MSISAM open with the separate Jackcess Encrypt library.
  • Reads properties of databases, tables, and columns. The original also reads query properties.
  • Writes only Jet4 and ACE files (Access 97 is read-only). The original can create complex columns from 5.0.3.

mdb-reader

  • Cannot read encrypted MSISAM files.
  • Cannot read the non-standard form of RC4 CryptoAPI.
  • For complex columns, returns only the contents of attachments.

access-parser

  • Has no public API that returns a table's column definitions.
  • Reads only per-column properties. Complex columns give only reference IDs.

MMKiwi.MdbReader

  • Cannot read rows of tables that contain Numeric, complex, BigInt, or DateTimeExtended columns.
