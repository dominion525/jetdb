Supports Access 97 to Microsoft 365

Read .mdb / .accdb files
without Microsoft Access

jetdb reads Microsoft Access databases (.mdb / .accdb) as a CLI tool, a Rust library, and an npm package. Beyond table data, it extracts queries, VBA, macros, and forms. Runs on macOS, Linux, and Windows.

Install GitHub 
# List the tables
$ jetdb tables jetdb-sample.accdb
# Extract VBA source code
$ jetdb vba show jetdb-sample.accdb modBilling
# Generate DDL for PostgreSQL
$ jetdb schema jetdb-sample.accdb --ddl postgres

No Access, no ODBC driver

Written entirely in Rust, with no dependency on C libraries. If all you have is the .mdb / .accdb file, you can open it as it is. Use it as a CLI or as a Rust library.

macOS, Linux, Windows

Runs even where there is no Windows or Access license.

Access 97 to Microsoft 365

Reads both .mdb and .accdb files, from Jet3 (Access 97) to ACE17 (Access 2019). Files created with Access for Microsoft 365 work too.

Password-protected files

Opens password-protected .accdb files (Agile, RC4 CryptoAPI, Standard and NonStandard AES) — just add --password.

Never modifies the original file

Opens files read-only and creates no lock file (.ldb / .laccdb). You can inspect a file someone handed you without worrying about breaking it.

Not just the data, but the whole app

Beyond pulling out tables, it extracts what you need to rebuild an Access application.

Note: Access 97 forms, reports, and VBA are not available. Print settings are shown as raw bytes, not decoded.

  • 03DDL

    Generates DDL for SQLite, PostgreSQL, MySQL, and Access SQL.

    jetdb schema jetdb-sample.accdb -T tblOrders --ddl postgres
    Show output 
    CREATE TABLE "tblOrders" (
    "OrderID" INTEGER NOT NULL GENERATED ALWAYS AS IDENTITY,
    "CustomerID" INTEGER NOT NULL,
    "ProductID" INTEGER NOT NULL,
    "Quantity" SMALLINT NOT NULL,
    "OrderDate" TIMESTAMP WITHOUT TIME ZONE NOT NULL,
    "Shipped" BOOLEAN,
    PRIMARY KEY ("OrderID")
);

ALTER TABLE "tblOrders" ADD CONSTRAINT "fkOrdersCustomers"
    FOREIGN KEY ("CustomerID") REFERENCES "tblCustomers" ("CustomerID");
ALTER TABLE "tblOrders" ADD CONSTRAINT "fkOrdersProducts"
    FOREIGN KEY ("ProductID") REFERENCES "tblProducts" ("ProductID");

  • 04Query SQL

    Reconstructs the SQL of saved queries.

    jetdb queries show jetdb-sample.accdb qryMonthlySales
    Show output 
    SELECT Format(tblOrders.OrderDate, 'yyyy-mm') AS SalesMonth, tblCustomers.CustomerName, Sum(tblOrders.Quantity * tblProducts.UnitPrice) AS Total
FROM (tblOrders INNER JOIN tblCustomers ON tblOrders.CustomerID = tblCustomers.CustomerID) INNER JOIN tblProducts ON tblOrders.ProductID = tblProducts.ProductID
GROUP BY Format(tblOrders.OrderDate, 'yyyy-mm'), tblCustomers.CustomerName
ORDER BY Format(tblOrders.OrderDate, 'yyyy-mm'), tblCustomers.CustomerName;

○ means usable with Access 2000 and later. Exceptions that apply only to Access 97 are in the notes.

  • MDB Tools reconstructs only SELECT queries (no JOIN or GROUP BY).
  • Jackcess opens password-protected .accdb files with the separate Jackcess Encrypt library. For the items in this table, the original Jackcess and the fork give the same results.
  • The MDB Tools library is LGPL-2.0 or later, and its CLI is GPL-2.0 or later.
  • mdb-reader does not support Standard AES encryption for password-protected .accdb files.
  • jetdb cannot read Access 97 form/report definitions or VBA.
  • MDB Tools can only add and update rows, through its library API.
  • Jackcess writes to Access 2000 and later; Access 97 files are read-only.

Ready to hand to AI agents

With the jetdb CLI installed, add the jetdb Skill and AI agents can read Access files with jetdb. Ask “I want to move this .accdb to PostgreSQL”, and the agent reads everything from the table definitions to the queries, VBA, and forms, and works through the migration.

Claude Code

Install it from the Plugin Marketplace.

/plugin marketplace add dominion525/agent-skills
/plugin install jetdb-cli@dominion525-skills

Other agents

Install it with the skills CLI. It supports Codex, Cursor, OpenCode, and more, and you choose where to install it when you run it. 

npx skills add dominion525/agent-skills --skill jetdb-cli

Even without the Skill, the CLI suits AI

  • Plain text output: CSV, SQL, VBA source, and so on, in forms that are easy to read and process.
  • Stable ordering: Lists are sorted by name. The same file always gives the same result.
  • Empty is not an error: When there are no tables or queries, it exits successfully with empty output. Errors go to standard error as a single line starting with jetdb:.

Runs in the browser, too

With the WebAssembly build (the npm package jetdb-wasm), browsers and Node.js can read the same things as the CLI: tables, queries, VBA, macros, forms, properties, and DDL, including password-protected files. Files never leave the browser. See the JavaScript API for how to use it.
